ATUALIZAÇÃO 18 (inclui tudo das anteriores — instale só esta)

1. Extraia este zip em C:\projetos\dojo-alcantara, substituindo tudo.
2. Firebase > Firestore > Regras: apague tudo, cole o firestore.rules deste zip e clique em PUBLICAR.
3. npm run build
4. git add .
   git commit -m "Menu lateral corrigido e pagina Materiais e PDFs"
   git push
